Course Overview

Web Development Fundamentals is a beginner-friendly course that teaches students how to create and design webpages.

Learning Outcomes

  • Create webpages using HTML5.
  • Create forms and use HTML5 elements.
  • Design webpages using CSS.
  • Use multimedia in webpages.
  • Understand CSS layout and positioning.
  • Use basic Bootstrap components.

Course Modules

1. HTML Fundamentals

Basic HTML tags, headings, paragraphs, lists and links.

2. HTML5 & Forms

HTML5 elements, forms, input types and validation.

3. Multimedia

Adding images, audio and video to webpages.

4. CSS Fundamentals

Colors, fonts, borders, backgrounds and spacing.

5. CSS Layout

Flexbox, positioning and webpage layouts.

6. Bootstrap

Using Bootstrap classes and components for webpages.
